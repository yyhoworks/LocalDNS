## 前端检查

通过构建、类型检查、Vitest（24 个文件 / 204 项）、ESLint、干净重建一致性与字体覆盖检查。

本机 Node 为 26.13.0，jsdom 27 的全局 Web Storage 在此环境会被 Node 原生的未启用存储属性覆盖；验证时设置 `NODE_OPTIONS=--no-experimental-webstorage` 后运行 `npm run --prefix frontend check`。此参数仅用于本机测试进程，不进入浏览器或安装包。

新增行为覆盖包括：

- 原生和旧式规则路径的 POST / PUT 等待完整 300000 毫秒，普通读取仍使用短超时；超时不重试。
- 单条广告、广告批量、单条分流、分组与全部分流更新的按钮状态、并发限制、失败恢复和结果待确认。
- 更新期间切换页签，以及离开规则页再回来；请求结束后当前页面恢复按钮并读取新结果。
- 中文分流组合名称、未知代码保留、上游错误名称、国外 IP 段的 API 映射。
- 下载保存期间弹窗显示“更新中…”，不会重复提交，也不会关闭后来打开的另一个弹窗。

Noto Sans SC / Noto Serif SC 子集增加“忙、握、繁”，保留原有字形和字重轴；源码 884 个汉字均被两个子集覆盖。

## 浏览器交互

`tools/verify_fjhai_ui.cjs` 使用本机 Edge 无头浏览器、1440px 桌面与 390px 手机模拟视口。全部网络限制为本机静态文件和模拟接口，不访问真实 VM。

两个视口各通过 4 项验收，共 8 项：

1. 从解析控制打开国外 IP 段，新增 CIDR，并确认 PUT 原文没有 `domain:` 前缀。
2. 单条广告下载超过虚拟 11 秒仍显示更新中，切换页签再回来状态保留，收到结果后恢复。
3. GeoIP 非 CN 分组更新显示更新中并在完成后恢复，页面没有横向溢出。
4. 日志筛选显示“国内规则待验证·国外无回应”，实际请求仍提交 `geosite_cn_unverified_noreply`。

报告与 6 张截图位于本地 `dist/fjhai-ui-verification/`。浏览器未捕获未处理脚本错误。手机证据来自模拟视口，不是物理设备测试；5 分钟超时通过模拟时间验证，没有实际等待 5 分钟或请求真实订阅。

Impeccable 检测发现原有 HTML 标题层级警告；本次沿用现有样式。浏览器中的标题和正文层级已按实际渲染核对。
