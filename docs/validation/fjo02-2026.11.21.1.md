## 真机与隔离验证

- 在 Alpine x86-64 的独立网络空间以非特权用户启动 FJN8C 与 FJO02 amd64-v3。新旧均通过回环 UDP/TCP DNS、管理 API 与配置一致性核对。
- 实测 FJO02 读取缓存来源、发布错误轮次指标；预取单字段 PUT 与国内、国外、国外 ECS 服务商写入均在隔离副本确认。
- 缺少服务商的旧配置不能启动 FJO02。已验证的迁移仅在暂存目录补字段，保留已有值。回退、保留 UI、原始快照恢复在升级测试中覆盖。
- 现有 Alpine amd64-v3 安装先更新独立升级服务，下载并核对完整备份的字节数与 SHA-256，再通过隔离预检切换内核，随后安装同一发行包的 UI。
- 实机确认 FJO02 / UI 2026.11.21.1，UDP/TCP 均成功，45 项受保护配置指纹与原备份一致，26 项已部署 UI 文件与构建清单一致。
- 真实设备桌面、手机各五页通过只读验收；浏览器没有写入设备设置。升级器保留整套回退快照，未在已验收的现网主动回退。
- ARM64、amd64-v1/v2 未执行真实 DNS 运行验证；含升级器的新装目录准备和两个架构的代理配置服务安装夹具通过。
