# 概览拖拽与系统管理 B 布局验证

版本：UI 2026.11.05.3 / DNS 核心 FJMOS。部署时间：2026-11-05 13:53 CST。范围：正式前端实现及 `192.168.8.2` 部署；未同步 GitHub，未创建公开发行版。

## 实现

- 概览沿用 `localdns-overview-block-order`、`localdns-overview-hidden-blocks` 的按站点保存方式，保持旧设置兼容。服务状态与指标卡共同排序，显隐独立。
- 默认锁定；解锁后支持鼠标拖动、触屏长按、视口边缘自动滚动、方向键排序、撤销及 Esc 取消。落下时持久化，取消不写入。离开概览、重新打开页面时锁定。
- 编辑期间停止整页静默刷新；已在请求中的静默刷新在提交 DOM 前再次检查编辑状态。重新渲染前释放指针、事件监听及拖动预览。
- 系统管理落实 B 双栏齐底层级版，使用实时缓存与分流任务数据，保留全部八项开关、缓存参数、变化报告、定时设置、DNS 重启和域名管理操作。桌面左右列共享网格高度，1100px 以下堆叠。
- 未知开关单独标记且禁用；缓存参数/定时配置读取失败时不提供可能覆盖旧配置的默认编辑入口；任务空值、进行中、失败和完成分别展示。
- GitHub 令牌仍只在浏览器保存，原有校验和脱敏逻辑保留，配置入口改为弹窗。

## 验证

- `npm run check` 全通过：构建、TypeScript、317 项测试（35 个文件）、ESLint、干净构建与 SHA-256 清单一致性、925 个源码汉字字体覆盖。
- Edge / Playwright 42 项检查通过：鼠标、键盘、触屏长按排序及自动滚动，锁定、撤销、取消、刷新持久化，服务/KPI 独立显隐，开关互斥，缓存查看/清空确认，定时配置、启动/取消、报告、GitHub 配置及未知状态。
- 1725、1440、1280、768、390px 检查无页面横向溢出；覆盖深色及浅色玻璃。功能测试的所有后端写请求均被本地模拟接收，未写生产配置。
- 线上单独只读点检通过：真实数据加载、8 个开关、桌面两栏底边均为 1245.96875px、缓存参数/GitHub 弹窗、默认锁定、键盘排序与撤销、390px 布局；无运行时错误，无写请求。
- DNS UDP/TCP 53 端口检查均为 RCODE 0，均有答案。

浏览器为 Windows 无头 Edge；触屏使用 Chromium 触控模拟，未覆盖 Safari、Firefox 或实体手机。
