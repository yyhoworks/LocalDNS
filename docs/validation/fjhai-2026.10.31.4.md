# FJHAI / UI 2026.10.31.4 验证记录

- 前端构建、TypeScript、206 项测试、ESLint、干净构建一致性与中文字体子集检查通过。
- Python 独立升级器 9 项测试覆盖 UI/内核/整套升级与回退、备份下载和本机摘要确认门槛、配置变化、暂存篡改、未知兼容性契约、未来同契约核心、重启恢复等待、取消和 HTTP 限制；原 UI 升级器 15 项与迁移 9 项测试通过。
- 在 Alpine 3.23.3 / OpenRC / amd64-v3 的独立运行目录、独立服务与独立端口上，运行真实 FJH7T → FJHAI 升级。内核单独升级保留完整 UI 文件摘要，整套升级使用目标 UI；两次完整回退恢复旧内核和旧 UI。测试未操作生产 DNS 服务。
- 每次真实内核升级及回退前，完整备份均经 HTTP 下载到本机 Windows 并核对 SHA-256 与大小后，才发出继续请求。隔离预检与切换后检查均实际运行。
- 真实 UI 升级与 UI 回退测试通过；UI 回退保留当前站点设置与最近构建资源。UI 单独升级不要求 UI 包原先的核心代号与实际核心完全相同，而要求兼容性契约一致。
- Edge 浏览器验证桌面 1440×1080、手机 390×844；暖色 terracotta 与深色玻璃外观各一组。三种入口、错误文件拦截、备份下载、本机分块摘要、继续按钮、任务锁定和关闭/重开均通过，无页面脚本错误。
- 在低磁盘空间条件下验证准备阶段会安全停止、不切换现网。预检使用临时回环端口，避免连续操作的 TCP 端口等待冲突。

本记录不宣称已运行 ARM64 或其他 CPU 指令等级的真实内核验收。FJHAI 四架构内核来自已校验的上一正式版，本次未变更内核二进制。
