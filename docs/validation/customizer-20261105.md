## 实现

- 顶栏只保留原有自定义图标，使用闭锁/开锁角标与解锁强调色区分状态。按钮仍打开设置弹层，锁定切换在弹层内完成。
- 删除列表上下箭头，每个排序单元只保留一个六点手柄。服务状态与指标卡共同移动、各自显隐。
- 列表拖动只预览 CSS 顺序，松手后保存现有存储键；拖动时首页同步预览，不提前写入存储。提交后按最终顺序重建列表，恢复手柄焦点与弹层滚动位置。
- Esc、指针取消、失焦、关闭弹层或切换锁定时取消当前预览。触屏手柄长按 160ms 启动，靠近弹层上下边缘只滚动弹层。键盘上下方向键保留，锁定时禁用。
- 手机顶栏直接显示自定义入口，弹层继续沿用现有停靠尺寸；不增加横向工具栏。
