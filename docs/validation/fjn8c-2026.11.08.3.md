# FJN8C / UI 2026.11.08.3 发布验证

日期：2026-11-08。修复安装器、升级器能力检查及下载错误提示，不更换 DNS 核心。

## 已确认的问题与修改

1. 一键安装 `--with-ui-updater` 的独立安装器清单漏掉 `core_upload.py`，而运行时必需该模块。
   运行模块与安装模块现在由 `install_localdns.py` 的两个常量统一声明，完整包 / UI 包和独立安装器共用清单。
   实际从发行载荷复制安装入口再执行，验证新装与重装，避免只测各子模块而漏测组合流程。
2. 单独升级 UI 不会替换常驻升级器。服务声明 `configurationMigrations: ["FJN8C"]`；新 UI 在未确认能力时阻止新内核准备并显示更新说明。
   UI 单独更新保持可用；已准备任务的备份下载、校验、继续和取消保持原流程。
3. 下载的笼统异常提示掩盖真实原因。现在分别识别超时、DNS、HTTP 网关、TLS 连接及证书校验错误。
   没有关闭 TLS 验证、自动更改代理或对不确定写入进行重试。

旧版已运行的 Python 服务无法仅靠替换 UI 自动获得新代码。因此已有设备需要在任务结束后重装一次升级器，
包括具备迁移逻辑但未声明能力的 2026.11.08.2 服务。该边界已在 UI、发行说明和网页升级文档明确说明。
