# FJMOS / UI 2026.11.01.4 — 代理工作区与用量统计

概览「代理流量」现在直接进入代理页。代理页以「流量统计 / 配置管理」组织，用量统计完整显示在页面中；不增加流量详情弹窗。

## 流量统计

- 今日、昨日、近 7 天、本月摘要；未采集的昨日显示「—」。
- 用量趋势、流量排行、每日明细三个页签共用日期范围；今日按小时，较长范围按天。
- 排行按设备、订阅或节点切换。设备使用现有别名，未知时显示 IP；原版未记录归属的历史字节列为「历史未分类」。
- 每日表格统一列宽、边距与数字右对齐，CSV 保留原始字节数和采集状态。
- 汇总与详情分开读取，详情按需加载。采集中断和跨日过期均有明确状态，旧日期不会冒充今日。

## 配置管理

复用原有编辑器、目录浏览、HTTP 获取、检查和保存流程。编辑器仍按需加载；有未保存修改或正在执行操作时，切换到统计仍遵循原来的离开确认。系统管理「编辑配置」入口直接打开配置管理。

## 采集服务升级

UI 升级包新增 `proxy-traffic/`，在代理服务所在 Linux 设备运行：

```sh
sh proxy-traffic/install.sh
```

旧版状态自动迁移，已有用量与连接基线保留。首次新安装先建立基线；已存在但损坏的状态不会静默清零。安装器备份旧程序与停止后的状态，不重启 DNS 或代理核心。

默认每 5 秒采样，每 30 秒保存，正常日志每 5 分钟一次；日合计、分类和分时分别保留 400、90、7 天。长期累计独立维护，不随日明细裁剪而减少。设备/订阅/节点聚合的剩余项保存在「其他」，显示前 20 名不丢累计依据。

这些数据是采样估算。短于采样间隔的连接，以及最后一张快照到关闭之间的尾部字节可能漏计；WebSocket 连接快照也不能保证消除这个边界。本功能不承诺与机场账单或代理核心进程累计一致。

## 升级与回滚

UI 使用现有 `install-ui.sh`，保留 `ui/config.js` 和 `ui/custom/`，包括网页升级服务地址、共享设置和采集数据。内核仍为 FJMOS。采集器回滚时先停止服务，一起恢复备份的程序和状态文件，再启动。

详细参数和边界见 [采集服务说明](../../services/proxy-traffic/README.md)。
