# FJMOS / UI 2026.11.03.2 · 顶栏精简与玻璃可读性

本版整理顶部工具栏（分组、紧凑版本徽标、统一线性图标、手机端精简），并提高流光毛玻璃皮肤在极端壁纸上的文字可读性。人文羊皮纸预设、字体、圆角与导航模式不变。

## ⚠️ 旧设备一次性操作

**2026.11.01.12 及更早版本的设备，需要在设备上手动运行一次以下命令**（root，在解压后的本版 UI 升级包 `LocalDNS_UI_2026.11.03.2_Update.zip` 或完整包目录中执行）：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

- 这一步安装新版升级服务，并在同一次运行中用该包升级已安装的配套服务（输出「配套服务：……」）。安装升级服务本身不重启 DNS。
- 此后每次在网页点击「升级 UI」/「升级 UI + 内核」，都会自动升级已安装的 ProxyConfig 服务和 Mihomo 回程守护。
- **不运行这一步时，网页点击「升级」仍然只更新界面**：旧升级服务不会执行发行包中的新代码，点多少次都一样。
- `--origin` 填浏览器实际访问网页的地址；HTTPS 反向代理等其他入口参数见 [网页升级指南](https://github.com/yyhoworks/LocalDNS/blob/main/docs/WEB_UPDATE.md#旧版设备需要一次性更新升级服务)。源码安装使用 `python3 tools/install_ui_updater.py --unified`，参数相同。
- 用一键脚本 `install.sh --with-ui-updater` 更新升级服务时，配套服务会在下一次网页升级时处理；需要立即处理可在解压后的升级包目录运行 `python3 ui-updater/companion_services.py --package .`（root）。
- 已在 2026.11.03.1 运行过这一步的设备无需重复，网页点击「升级」即可。

## 顶栏精简分组

- 顺序统一为 **搜索 · 版本徽标 │ 代理▾ │ 概览 外观 流光 │ 刷新 主题**，水平导航与垂直导航共用同一结构，水平导航恢复分组分隔线。
- **版本徽标**：原来两行的「UI 2026.11.03.1 / 已是最新」按钮改为单行等宽徽标 `v11.03.2`；完整版本与状态放在悬停提示与读屏标签里。有新版本时改为强调色描边加圆点，并显示 `v当前 → 新版`。点击仍打开「版本与更新」。
- **外观按钮误高亮已修复**：外观（壁纸）按钮不再常驻高亮，只在面板展开时高亮；概览自定义按钮同理。
- **流光**：开启时不再整块实底，改为图标下方的强调色小圆点。
- **图标统一**：顶栏的 概览 / 刷新 / 主题 / 重启 以及搜索、外观、代理箭头统一为 1.8 描边线性图标；导航、卡片标题等处的填充图标不受影响。
- 代理入口去掉外框与内部竖线，改靠分组分隔线区分。
- **手机（≤600px）**：顶栏只留 搜索、代理、外观、刷新、主题五个按钮；「拓扑流光」开关、「自定义概览卡片」（仅概览页）和「版本与更新」移到外观面板最上方的 **快捷入口**，有新版本时 Logo 右上角显示强调色圆点。同时修复了搜索按钮压在 Logo 上的问题。
- **平板（601–900px）**：工具按钮只显示图标，徽标只显示当前版本，不再挤压搜索框。
- 强调色跟随皮肤：流光毛玻璃为蓝色，人文羊皮纸为陶土色。

## 玻璃皮肤可读性

- **材质下限**：遮盖度下限从 55% 提高到 **62%**，并随模糊半径自动提高（模糊 <6px 为 80%，<10px 为 70%，≥10px 为 62%）；背景暗化下限从 15% 提高到 **20%**。拖动模糊滑块时遮盖度下限同步变化，低于下限会自动抬高并保存，同时显示说明。旧版本保存的低值读取时自动钳制到新下限。
- **文字与强调色**（仅流光毛玻璃）：深色玻璃 `text-2` #B0B9C9 → #DCE2EC、`text-3` #8C96A8 → #C3CCDA、`primary-light` #60A5FA → #BCD6FE；浅色玻璃 `text-3` #475569 → #3E4A5C、`primary-light` 新增深色覆盖 #1D40AA；成功 / 危险 / 信息状态色同步调整。
- **对比度**（最差情形：深色玻璃配纯白壁纸、浅色玻璃配纯黑壁纸，取下限值）：

| 角色 | 深色玻璃 改前 → 改后 | 浅色玻璃 改前 → 改后 |
|---|---|---|
| text-1 | 4.71 → **6.21** | 8.02 → 9.29 |
| text-2 | 2.58 → **5.16** | 4.65 → 5.39 |
| text-3 | 1.71 → **4.15** | 3.40 → **4.67** |
| primary-light | 2.00 → **4.54** | 1.14 → **4.62** |
| success | 3.34 → 4.63 | 3.45 → 4.93 |
| danger | 2.68 → 4.60 | 2.91 → 4.56 |
| info | 2.82 → 4.54 | 3.01 → 4.62 |

  概览页实测：深色玻璃、纯白壁纸、下限值下，对比度低于 3:1 的文字节点从 3 个降到 0。三级文字层次保留（text-1 > text-2 > text-3）。
- **无障碍兜底**：浏览器不支持 `backdrop-filter` 时玻璃改用强实底；系统开启「减少透明度」或「提高对比度」时去掉模糊、表面接近实底、次要文字提亮；「提高对比度」时次要文字与正文同色、边框加深；Windows 强制颜色模式下去掉模糊和壁纸层，卡片使用系统边框色。

本版 DNS 内核仍为 FJMOS，配置、规则与上游未改动；更新 UI 无需重启 DNS。
