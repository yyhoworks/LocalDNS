# FJMOS / UI 2026.11.01.11 · 概览块自适应布局

概览页的块布局改成自适应，调整顺序或隐藏块都不再留下空白；顺带修掉慢查询整块消失的问题。

- **不再有空洞**：9 个块改成按基准宽度自动换行，行内填满剩余空间。趋势图与结果占比仍是 2/3 + 1/3，缓存池与慢查询仍是 5/12 + 7/12，其余整行；单独成行的块自动拉满整行。
- **慢查询不会再消失**：上一版在 ≥1251px 时把它的高度交给同行邻居，单独成行（调整顺序或隐藏缓存池）会变成 0 高度、整块看不见。现在高度由内容决定、上限 560px，超出后表格内部滚动。
- **手机端「链路健康」改分行**：窄屏下「最近 N 次查询」「0 次 SERVFAIL」「慢查询 N 组」不再从词组中间断开。
- 顺序仍按浏览器保存，弹层里的 ▲▼ 与「恢复默认」不变。

## 安装与服务更新

已有安装先使用 UI 升级包中的 `install-ui.sh /opt/localdns` 更新界面，保留 `ui/config.js` 和 `ui/custom/`。随后在解压目录运行：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

源码使用 `python3 tools/install_ui_updater.py --unified`，其余参数相同。

**只更新网页不会更新独立升级服务。** 安装升级服务不重启 DNS。目录、网页来源和 HTTPS 代理入口按实际安装配置填写，详见 [网页升级指南](../WEB_UPDATE.md)。

本版只含界面改动，DNS 内核、配置、规则与上游均未改动。
