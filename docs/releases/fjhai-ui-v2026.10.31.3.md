# FJHAI / UI 2026.10.31.3

适配用户提供的 FJHAI 内核，补齐中文提示和规则下载等待状态。

## 界面变化

- 上游错误分类改为超时、连接失败、连接中断、拒绝或不可达、回答格式错误等中文名称。
- 分流结果支持按前缀与后缀组合翻译；概览、查询标签、筛选器和详情使用同一套名称。内部代码、筛选参数和原始日志保持原值，未知代码保留以便排查。
- 广告与在线分流写入统一使用 5 分钟等待时长，包含保存订阅时可能触发的下载。
- 单条、分组和全部更新显示“更新中…”，更新期间禁止重复提交与冲突修改；切换页签或离页返回仍保留操作状态。
- 超时不等同于服务器失败，提示稍后刷新确认；分组和全量更新保留已经完成的结果，不自动重试。
- “解析控制”补上“国外 IP 段”，支持 IP/CIDR 原文编辑，不添加域名匹配前缀。

## 内核与配置

FJHAI 的新装缓存上限为 30 万 / 20 万 / 5 万 / 5 万，总预算按上限比例分配。界面从接口读取实际值；升级工具保留原上限和预算。新模板移除上游包的私人别名、手工规则、特定网络上游、任务时间和运行数据。

完整包包含 amd64-v1 / v2 / v3 / arm64 四种内核。输入包 `LocalDNS_FJHAI.zip` 的本地 SHA-256 为 `cb2ee790d3c835066de51295bae1fe95af85b57c0b4605323c0d895b6d0d5800`，用于记录本次用户提供的来源，未作独立发布方认证。

## 升级

**旧核心必须使用完整包迁移。** 先下载备份上游、自定义规则、修改过的客户端别名与订阅，再准备新目录并恢复原设置。工具同时保留其余配置，要求本机备份摘要与原归档一致，并在切换前通过隔离验证。具体命令见 [FJHAI 升级指南](../FJHAI_UPGRADE.md)。

UI 更新包只更新已运行 FJHAI 的界面，不升级内核。包外 `SHA256SUMS.txt` 和包内 `MANIFEST.sha256` 可用于校验。

## 验证与限制

验证记录见 [FJHAI 适配验收](../validation/fjhai-2026.10.31.3.md)。已在 Alpine Linux x86-64 完成 FJH7T → FJHAI 完整迁移：先下载并校验备份，再通过隔离预检、整体切换及 TCP/UDP DNS 验收；原配置、名单、别名和订阅的指纹保持一致，实际概览、日志、上游与规则页面加载正常。

ARM64 和其他 Linux 发行版未做实机验证；5 分钟等待通过模拟时间测试，未触发生产环境的订阅下载更新。
