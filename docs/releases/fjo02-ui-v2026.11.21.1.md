## 已有安装

只更新界面可用 Update.zip，不重启 DNS，也不自动替换网页升级服务。已配置网页升级的设备，完成或取消当前任务后，从本版升级包解压目录重新安装服务：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

目录、Origin、端口和 HTTPS 条件沿用现有安装，再用「版本与更新」上传内核 ZIP 或准备整套升级。下载并校验完整备份后才切换，DNS 短暂重启；可从升级器恢复上一版本。详见 [网页升级指南](../WEB_UPDATE.md)。
