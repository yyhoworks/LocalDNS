# FJN01 / UI 2026.11.06.1

界面一致性与可读性修正，只改前端。FJN01 内核、默认配置、升级服务和代理配置服务 1.7.1 保持不变。

- 页面标题与导航、浏览器标签页统一：日志、解析、分流、系统，不再出现「查询日志 / DNS 管理 / 规则管理 / 系统管理」等另一套名称；搜索旧名称仍能跳到对应页面。解析页的「卡片 / 列表」切换并入右侧操作区，标题恢复左对齐。
- Claude 浅色皮肤：分流结果等主色徽章的文字从 `#C96442` 加深为 `#A44B2D`，纸面上的对比度从 3.77:1 提高到 5.60:1；徽章底色改用同色系，不再是蓝底配橙字。
- 字号收敛为 11 / 12 / 13 / 14 / 16 / 18 / 20 / 22 / 24px（28px 以上的展示数字不变）。原有 179 处非档位字号只向上取整、不缩小，最小字号从 8px 提高到 11px。新增测试阻止再写入档位外的字号。

## 如何升级

在网页「版本」中直接升级 UI 即可，不需要重新安装升级服务或切换内核。也可下载本版 Update.zip 手动替换 UI，或使用 Full.zip 全新安装。

Full.zip 沿用 2026.11.05.6 的四架构 FJN01 二进制及干净默认配置；Update.zip、Full.zip 内的升级服务工具与 .6 相同；Service.zip 仍为代理配置服务 1.7.1。

验证记录见 [本版发布验证](../validation/fjn01-2026.11.06.1.md)。旧版本发布附件保持不变。
