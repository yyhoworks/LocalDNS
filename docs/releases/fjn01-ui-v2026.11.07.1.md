# FJN01 / UI 2026.11.07.1

修复字体不统一和手机端设备操作问题。已有 FJN01 用户在网页「版本与更新」中点击「检查更新」，选择「升级 UI」即可应用本版修复。

- 设备页标题、大数字接入全局字体设置；IP、筛选数量和请求计数使用统一等宽字体，中文「次」保持正文字体。
- 补齐全站 `.mono` 与代码文本的字体规则；外观面板中文标签、系统页日期和历史记录、手机端缓存字段名使用正文字体。
- 手机端设备筛选条在内容区内横向滚动，不再伸出页面。
- 批量操作栏只在选中设备时显示，手机端位于底部导航上方，浅色主题使用对应底色和边框。
- 点击「取消」时同时清除实际选择与行勾选框。

## 升级与下载

- `LocalDNS_FJN01_UI_2026.11.07.1_Full.zip`：包含四架构 FJN01 的完整安装包。

本版只改前端。Full.zip 沿用已发布 2026.11.06.1 的 FJN01 内核与干净默认配置，配套升级工具和服务代码保持不变。只升级 UI 无需重启 DNS，也无需重新安装升级服务。

自动检查更新间隔为 6 小时；发布后可点击「检查更新」立即刷新。遇到 GitHub 限流时，按界面提示等待后重试。
