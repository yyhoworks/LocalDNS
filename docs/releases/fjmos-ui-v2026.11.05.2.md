# LocalDNS UI 2026.11.05.2

配套配置服务升级至 **1.7.1**，修复钩子失败后的核心状态误报和错误信息中的凭据泄漏。

- 钩子执行失败后继续确认核心在线，回滚后再次检查。只有检查通过才显示「核心在线检查通过」；无法确认时明确提示检查服务。
- 保存启动配置前检查钩子路径和执行权限，错误钩子在备份、文件替换及重载之前被拒绝。读取、检查和备用文件保存仍可使用。
- 为健康检查预留时间并有限重试；钩子超时后仍检查核心，应用与回滚分别受原有 45 秒预算约束。
- 启动告警和保存错误保留错误类别、退出码，不回显实际命令、参数及任意钩子输出。

更新包内嵌配置服务 1.7.1。支持配套服务升级的网页更新执行端会升级已安装的配置服务；也可解压独立 Service.zip 执行安装脚本。升级保留已有服务配置，因此无效的 `postReload` 仍需在 `/etc/localdns-proxy-config.json` 中修正，并重启配置服务生效。

`postReload` 使用 argv 数组，例如 `["/sbin/rc-service", "mihomo-gateway", "restart"]`；请按设备实际路径配置。通过配置服务的 `/healthz` 可核对版本为 `1.7.1`。

验证记录见 [2026.11.05.2 验证说明](../validation/fjmos-2026.11.05.2.md)。
