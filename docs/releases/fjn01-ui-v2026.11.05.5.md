# FJN01 / UI 2026.11.05.5

本版将核心升级为 FJN01，并完成缓存与功能设置的 UI 适配。包含此前本机验收的概览拖拽和系统管理布局。

- **概览自定义**：一个入口显示锁定/解锁状态，集中控制显隐和排序；首页模块、面板内六点手柄均可拖动。支持触屏长按、键盘排序、Esc 取消、撤销和按浏览器保存。
- **系统管理**：B 双栏齐底布局，缓存、刷新任务和功能设置分级展示。定时计划与任务进度突出，八项开关按请求过滤、缓存策略、客户端分流分组。
- **缓存详情**：系统页和概览共用表格、域名/类型搜索与每页 50 条分页；展示条目上限、内存使用、预算、新鲜期和保留期，保留原始内容。搜索仅覆盖内核返回的明细，界面明确说明与缓存总量的差异。
- **缓存参数**：可编辑总内存预算，0 表示不限内存、仍受条目上限约束。预算立即生效，各池参数依内核回读标记待重启。保存前完整校验，只提交变化值；部分失败后重试会先核对已保存的值。
- **开关说明**：根据当前开关状态说明行为，包括关闭类型屏蔽后仍处理 FakeIP 域名的 HTTPS/SVCB，以及名单内外客户端的直连策略。读取失败不假定为关闭。

## 升级方式

- `Full.zip`：FJN01 完整包，含 amd64-v1/v2/v3、arm64 内核及当前 UI；通过统一升级服务的完整升级流程保留已有配置、规则与个人资源。
- `Update.zip`：仅更新 UI，包含代理配置服务 1.7.1 和配套升级工具；不会把正在运行的旧核心自动变成 FJN01。也可先通过内核上传入口升级用户提供的 FJN01 ZIP，再安装 UI 更新。
- `Service.zip`：代理配置服务 1.7.1 独立安装包，服务代码与上一版相同。
- 包内提供文件清单，附件提供 `SHA256SUMS.txt`。完整包沿用已发布的干净默认配置，仅导入原包中四种架构的核心文件，不导入原包中的示例名单、缓存或个人设置。

核心切换前应下载并验证完整备份。`querylog.persist=false` 时，重启后内存日志和进程计数会重新开始；已落盘配置及数据保留。测试不涵盖所有平台的实际启动，本次真实启动与 DNS 验证平台是 Alpine amd64-v3。
