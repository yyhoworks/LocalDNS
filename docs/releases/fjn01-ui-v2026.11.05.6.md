## 已有用户如何应用修正

网页中可以正常升级 UI 到 2026.11.05.6。**本次代码修复属于独立升级服务，仅点击「升级 UI」不会替换运行中的升级器。** 要应用修复，请下载本版 Update.zip 或 Full.zip，解压后在服务器运行：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

使用实际安装目录和浏览器访问来源；已有自定义监听、端口或反向代理地址按原设置填写。请等升级任务完成后再安装服务。安装升级服务不重启 DNS；完成后在版本弹窗点击「刷新连接与状态」。详情见 [网页升级指南](../WEB_UPDATE.md)。

使用统一升级服务的 FJMOS 设备仍可只升级 UI，保留 FJMOS 核心。已经运行 FJN01 的用户无需重复切换内核。本次 Full.zip 沿用 .5 的四架构 FJN01 二进制及干净默认配置；Update.zip、Full.zip 都包含修正后的升级服务工具，Service.zip 仍为代理配置服务 1.7.1。

验证记录见 [.6 发布验证](../validation/fjn01-2026.11.05.6.md)；FJMOS 实测详情见 [.5 发布后复核](../validation/fjn01-2026.11.05.5.md)。旧 `.5` 发布附件保持不变。
