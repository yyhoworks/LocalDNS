# FJN8C / UI 2026.11.08.2

适配作者提供的 FJN8C 内核，并补齐从旧核心升级时必需的配置迁移。

- 系统 → 功能设置 → 缓存策略新增“缓存预取”，单独保存该字段，不覆盖其他开关。
- 解析页支持查看、选择或自定义服务商；同一服务商请使用相同名称，因为该字段影响内核投票。
- 国内、国外、国外 ECS 上游需要服务商；代理组不支持该字段。FJN01 等旧内核不显示或发送新字段。
- 配置读取失败保持未知，页面切换后旧响应不回写；保留未知节点字段、草稿与取消行为。
- 继续保留上一版的代理流量变化与跨午夜升级校验修复。

## 已有设备的升级顺序

**先重新安装本版网页升级服务，再上传 FJN8C ZIP 或执行整套升级。旧升级器不会补齐 FJN8C 必需字段。**

1. 下载本版 Update.zip 和 `SHA256SUMS.txt`，核对 SHA-256，解压到独立目录。
2. 完成或取消现有等待任务，然后在解压目录以 root 执行：

   ```sh
   python3 ui-updater/install_ui_updater.py --unified \
     --dir /opt/localdns --origin http://服务器IP:9099
   ```

3. 目录、Origin、自定义端口和 HTTPS 参数沿用实际安装值，详见 [网页升级说明](../WEB_UPDATE.md)。
4. 刷新网页连接，选择“整套升级”，或上传作者 FJN8C ZIP 仅升级内核。
5. 下载完整备份并选择下载文件校验，通过隔离预检后再确认切换。
6. 升级后核对服务商归属；将同一真实服务商的节点改为相同名称。

迁移仅发生在暂存目录：缺失的 `prefetch` 补为新内核实际默认值 `true`，已有 `false` 不变；
缺失 / 空白的服务商按节点补为独立的 `未标注 · 分组-序号`，不推测运营商或合并投票身份。
原始配置和备份不变，快照回滚还原旧内核与原始设置。原缓存上限继续保留，不套用作者示例中的新上限。

单独升级 UI 可以继续配合 FJN01 使用，但不会更新服务器常驻升级器。
本次不使用作者安装脚本覆盖现有 UI、设置、地理订阅或备份。
