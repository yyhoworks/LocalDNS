# FJN8C / UI 2026.11.08.3

修复一键安装与内核升级链路。DNS 内核继续使用上一版的四架构 FJN8C，默认配置与规则不变。

- 一键安装 / 更新的 `--with-ui-updater` 路径补齐 `core_upload.py`，完整复制独立升级器所需模块。
- 缺模块或模块语法无效时，安装器在覆盖当前升级服务前停止；存在活动任务时，一键更新也在改动 UI 前停止。
- 升级器声明 FJN8C 配置迁移能力。新 UI 在能力未知时显示升级服务安装说明，阻止新内核准备；UI 单独更新仍可用。
- 已有备份任务继续支持下载、校验、确认和取消，不因新能力检查失去操作入口。
- 下载错误明确区分连接 / 读取超时、DNS、HTTP 网关和证书校验失败。

## 已有设备如何更新

**单独更新 UI 不会更新正在运行的升级服务。请先完成或取消已有任务，再重新安装本版升级服务。**

1. 下载本版 Update.zip 和 `SHA256SUMS.txt`，核对摘要后解压到独立目录。
2. 在解压目录以 root 执行，目录、Origin、自定义端口和 HTTPS 入口使用原安装值：

   ```sh
   python3 ui-updater/install_ui_updater.py --unified \
     --dir /opt/localdns --origin http://服务器IP:9099
   ```

3. 刷新网页的“版本与更新”连接，确认升级服务更新提示消失，再准备内核升级。

2026.11.08.2 升级器没有新的能力声明，更新到新 UI 后也需执行上述一次重装。
已经处于备份确认阶段的任务可以先按原流程完成，不能在任务执行中重装升级服务。
新的一键安装 / 更新可使用 `--with-ui-updater`，本版会完整安装升级服务；参数见 [网页升级说明](../WEB_UPDATE.md)。

## GitHub 下载不可达时

能取得版本信息，仍可能无法访问 GitHub 下载域名；浏览器和服务器使用的网络也可能不同。
连接超时或 HTTP 504 应检查服务器网络和代理，不应直接关闭证书校验。
已有设备可先安装新版升级器，再上传本地作者内核 ZIP，避免服务器下载 GitHub 附件。
全新安装可使用校验过的离线发行包及 `--package-dir`。
本版没有自动更改系统 DNS、代理规则或 TLS 检查。
