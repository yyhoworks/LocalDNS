# FJN01 / UI 2026.11.07.2

调整设备名称的字号与字重，并让在线升级的主操作符合实际更新内容。

- 设备名称改为 **14px、中等字重（500）**，较原先的 16px / 600 更紧凑；IP 继续使用 12px 等宽字体。
- **只有 UI 更新时，「升级 UI」显示实心主题色。** 即使发行版同时提供完整安装包，也不会将主色分给同内核重装。
- UI 与内核都有更新时突出「升级 UI + 内核」，单独「升级 UI」仍可点击；选择内核 ZIP 后优先突出已选文件的操作。
- 深浅玻璃与 Claude 两种皮肤均使用各自主题色，手机端保持相同判断。

## 如何升级

在「版本与更新」点击「检查更新」，选择「升级 UI」即可。自动检查间隔为 6 小时；手动检查可立即获取最新版本，GitHub 限流时按页面提示等待后重试。

本版包含：

- `LocalDNS_UI_2026.11.07.2_Update.zip`：UI 升级包。
- `LocalDNS_FJN01_UI_2026.11.07.2_Full.zip`：含四架构 FJN01 的完整安装包。
- `LocalDNS_ProxyConfig_UI_2026.11.07.2_Service.zip`：代理配置服务 1.7.1 独立包。
- `SHA256SUMS.txt`：安装包校验值。

Full.zip 沿用已发布 2026.11.07.1 的内核与干净默认配置；升级服务与代理配置服务代码保持不变。只升级 UI 无需重启 DNS，也无需重新安装升级服务。

本版改动生效后，后续仅 UI 更新会突出对应按钮。当前已安装的旧 UI 仍使用旧版按钮样式，可选择仍然可用的「升级 UI」应用本版修复。

验证记录见 [本版发布验证](../validation/fjn01-2026.11.07.2.md)。
