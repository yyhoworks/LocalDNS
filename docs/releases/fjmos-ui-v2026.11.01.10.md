# FJMOS / UI 2026.11.01.10 · 概览内容块自定义

概览页新增「自定义显示」：可以勾选显示哪些内容块，也可以调整块的先后顺序。

- **入口在顶部工具栏**（外观左侧的网格图标），只在概览页出现。勾选与顺序按浏览器保存，换浏览器或清缓存后回到默认。
- **九个内容块**：服务运行状态、指标卡、快捷控制条、响应趋势图、查询结果占比、解析链路拓扑、访问排行、缓存池状态、慢查询排行。
- **默认顺序与 2026.11.01.9 一致**：没有改过设置的用户看到的页面和上一版相同。
- 「恢复默认」一次复位显隐与顺序；弹层支持点击文字勾选、▲▼ 调序，Esc / 关闭按钮收起并把焦点还给入口。
- 被隐藏的块仍然正常渲染和取数，只是不绘制；重新勾选后立即出现，不需要等下一次刷新。
- 顺序按 12 栏 grid 的 `order` 应用，不改动页面结构；服务运行状态与指标卡在页面增强后同处一个分组，作为整体移动。

## 修复

- 慢查询排行在 ≥1251px 下单独成行时高度会归零、整块看不见（缓存池与它是 5+7 的等高对，离开邻居后没有高度来源）。现在给了一个下限，独占一行时仍能正常显示。
- 概览页每 30 秒静默重渲染后，自定义顺序不再跳回默认。

## 安装与服务更新

已有安装先使用 UI 升级包中的 `install-ui.sh /opt/localdns` 更新界面，保留 `ui/config.js` 和 `ui/custom/`。随后在解压目录运行：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

源码使用 `python3 tools/install_ui_updater.py --unified`，其余参数相同。

**只更新网页不会更新独立升级服务。** 安装升级服务不重启 DNS。目录、网页来源和 HTTPS 代理入口按实际安装配置填写，详见 [网页升级指南](../WEB_UPDATE.md)。

本版只含界面改动，DNS 内核、配置、规则与上游均未改动。
