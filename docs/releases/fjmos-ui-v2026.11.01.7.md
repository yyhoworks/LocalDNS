## 安装与服务更新

已有安装先使用 UI 升级包中的 `install-ui.sh /opt/localdns` 更新界面，保留 `ui/config.js` 和 `ui/custom/`。随后在解压目录运行：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

源码使用 `python3 tools/install_ui_updater.py --unified`，其余参数相同。目录、网页来源和 HTTPS 代理入口按实际安装配置填写。

**只更新网页不会更新独立升级服务。** 旧服务可能没有内核上传能力，也不包含新的服务器限流降级逻辑。完成服务更新后点击“刷新连接与状态”。安装升级服务不重启 DNS。

GitHub 官方下载地址也受限时，仍需等待或使用离线包。首次检查无缓存时无法绕过“发现最新发行标签”这一步；可从发布页确认标签后用安装器 `--version` 指定。详见 [网页升级指南](../WEB_UPDATE.md)。
