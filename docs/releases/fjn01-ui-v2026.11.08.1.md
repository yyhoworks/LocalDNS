# FJN01 / UI 2026.11.08.1

修复代理流量持续刷新导致网页内核 / 整套升级误报“下载备份后设置发生变化”的问题。

- 流量计数变化和跨午夜等待不再误触设置冲突，完整升级、仅内核升级和上传原作者内核均适用。
- 归一化仅用于现网比对；真实设置、未知字段、其他 UI 文件和内核文件变化仍会阻止升级。
- 暂存目录、预检和旧快照保持逐字节哈希校验，旧版快照无需迁移即可回滚。
- 补齐跨日、任务重启、旧快照恢复、暂存 / 快照改动和无效流量 JSON 的回归测试。
- FJN01 内核、干净默认配置和代理配置服务 1.7.1 沿用上一正式版；不更换 DNS 核心或后端协议。

## 如何使修复生效

**本次需要重新安装网页升级服务。** 单独点击“升级 UI”或刷新网页不会替换正在运行的升级器。

1. 下载本版 Update.zip，核对同页 `SHA256SUMS.txt`，解压到服务器上的独立目录。
2. 有等待中的任务时，先完成或取消任务，再从解压后的目录以 root 运行：

   ```sh
   python3 ui-updater/install_ui_updater.py --unified \
     --dir /opt/localdns --origin http://服务器IP:9099
   ```

3. 按实际安装值填写目录、Origin；自定义端口或 HTTPS 代理继续使用原有参数，见 [网页升级说明](../WEB_UPDATE.md)。
4. 回到网页刷新连接，再重新准备此前失败的升级任务。界面可通过“升级 UI”更新到本版，无需为此重启 DNS。

重装升级服务会更新该服务，并按既有流程检查已安装的配套服务；不会新装未启用的配套服务。
无需删除 `traffic.json`、`traffic-detail.json`、用户设置或历史备份。
完整 / 内核升级仍须下载完整备份并校验 SHA-256；失败时继续使用已有自动恢复和快照回滚流程。

- `LocalDNS_UI_2026.11.08.1_Update.zip`：UI、修正后的升级工具及配套服务载荷。

- `LocalDNS_ProxyConfig_UI_2026.11.08.1_Service.zip`：代理配置服务 1.7.1 独立包。
- `SHA256SUMS.txt`：三个安装包的 SHA-256 校验值。

验证使用隔离夹具，不代表本次已在真实设备执行内核切换。
