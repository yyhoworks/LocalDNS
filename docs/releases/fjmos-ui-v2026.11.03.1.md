# FJMOS / UI 2026.11.03.1 · 网页升级同步更新配套服务

本版修复概览「自定义显示」弹层、升级服务与三个配套服务的稳定性问题，并让网页升级时一并更新已安装的代理配置服务和 Mihomo 回程守护。

## ⚠️ 旧设备一次性操作

**2026.11.01.12 及更早版本的设备，需要在设备上手动运行一次以下命令**（root，在解压后的本版 UI 升级包 `LocalDNS_UI_2026.11.03.1_Update.zip` 或完整包目录中执行）：

```sh
python3 ui-updater/install_ui_updater.py --unified \
  --dir /opt/localdns --origin http://服务器IP:9099
```

- 这一步安装新版升级服务，并在同一次运行中用该包升级已安装的配套服务（输出「配套服务：……」）。安装升级服务本身不重启 DNS。
- 此后每次在网页点击「升级 UI」/「升级 UI + 内核」，都会自动升级已安装的 ProxyConfig 服务和 Mihomo 回程守护。
- **不运行这一步时，网页点击「升级」仍然只更新界面**：旧升级服务不会执行发行包中的新代码，点多少次都一样。
- `--origin` 填浏览器实际访问网页的地址；HTTPS 反向代理等其他入口参数见 [网页升级指南](../WEB_UPDATE.md#旧版设备需要一次性更新升级服务)。源码安装使用 `python3 tools/install_ui_updater.py --unified`，参数相同。
- 用一键脚本 `install.sh --with-ui-updater` 更新升级服务时，配套服务会在下一次网页升级时处理；需要立即处理可在解压后的升级包目录运行 `python3 ui-updater/companion_services.py --package .`（root）。

## 新增：网页一键升级配套服务

- UI 升级包与完整包内嵌 ProxyConfig Service 程序（Linux amd64 / arm64）、Mihomo 回程守护脚本和配套服务升级器 `ui-updater/companion_services.py`；发行附件恢复包含 `LocalDNS_ProxyConfig_UI_2026.11.03.1_Service.zip`。
- 新版升级服务在「升级 UI」或「升级 UI + 内核」验收后（「只换内核」不处理），只对**已安装**的代理配置服务 / 回程守护替换程序：核对程序摘要与 ELF 架构，保留 `/etc` 配置，先备份，重启后健康检查，失败即恢复原程序。未安装的服务不会被安装。
- 配套服务失败只作警告，不影响本次 UI 升级；结果写入 `GET /upgrade/status` 的 `companions` 字段与完成提示。

## 概览「自定义显示」弹层

- 弹层不再被 30 秒静默刷新收起；打开弹层时暂停静默刷新，页面滚动时跟随按钮重新定位。
- 「服务运行状态」与指标卡合为一组：显隐各自独立，排序整组移动；旧版分开保存的顺序自动归位。
- 窄屏弹层底部不再被裁切；宽屏按钮靠下时弹层翻到上方。

## 升级服务

- 成功切换后每类快照 / 备份只保留最近 2 份，暂存与备份不再逐代嵌套旧快照。
- 升级服务启动时恢复失败不再让服务退出：记录为需要处理（needs_attention），状态接口仍可用，变更操作返回 409。
- `install-ui.sh` 使用统一安装锁协议，与升级服务互斥。

## 配套服务修复

- **代理配置服务**：备份清理只匹配本文件自己的备份，不再误删刚生成的备份；停止服务时等待进行中的保存 / 重载完成。
- **Mihomo 回程守护**：修复失败时按 2 秒到 300 秒指数退避，日志只在状态变化时记录，不再刷屏。
- **代理流量采集器**：控制器返回不完整响应时不再退出；写入前 fsync；OpenRC 改用 supervise-daemon 自动拉起。

本版 DNS 内核仍为 FJMOS，配置、规则与上游未改动；更新 UI 无需重启 DNS。
